# SKY TRACK 田徑選手管理系統

把選手名單、運動處方、訓練日誌與每次跳躍監控整合在同一個本機 Web App。

## 目前功能

- 團隊儀表板：準備度、處方、訓練負荷、跳躍趨勢與最近動態。
- 選手管理：姓名、專項、年齡、組別與個人指標。
- 運動處方：目標、強度、項目、教練注意事項與完成狀態。
- 訓練日誌：訓練時間、RPE、睡眠、痠痛、心情與回饋。
- 跳躍監控：逐跳高度、RSI-Mod、接觸時間、最佳值與 CV。
- 整合報告：同一選手的處方、實際負荷、恢復與跳躍反應。
- 本機保存：資料存於瀏覽器 `localStorage`，可匯出 JSON 備份與跳躍 CSV。
- 名單來源：`AI工作坊-報名者列表(1106).xlsx` 的姓名、運動項目、身分別與任職單位，共 10 筆；在本原型中暫視為選手名單。
- 輸入選單：運動項目、身分別、年齡、訓練時間、RPE、睡眠、痠痛、心情與測驗類型採標準選單。
- 品牌頁尾：臺灣運動健康科技學會 Logo、2026 年版權及 2026 年 11 月版本資訊。
- 產品識別：使用 AthleteTrack 圖案 Logo；Firebase Hosting 採獨立 site `athlete-track-skyfu218`。

## 執行

可直接開啟 `index.html`，或在資料夾內執行：

```bash
python3 -m http.server 4173
```

再開啟 `http://localhost:4173`。

## 資料與限制

- 目前為單機原型，未連接 Firebase、登入、多人權限或雲端同步。
- 內建資料為介面示範資料，不代表真實選手紀錄。
- 準備度是依睡眠、痠痛、心情、RPE 與跳躍變化做的規則式提示，不是醫療診斷。
- 正式使用真實選手資料前，應定義個資權限、備份、資料保留與刪除機制。
